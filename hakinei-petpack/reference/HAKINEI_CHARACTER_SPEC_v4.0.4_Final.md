# 哈基奈（Hakinei）V4 角色設計最終定案規格書（v4.0.4 Final）

**狀態：正式角色規格；尚待 Codex 本地同步與新母版原件核對。**
**視角：**「畫面左／右」均為正面觀看者視角。「角色左／右」以角色自身為準。
**用途：** Hakinei Pet Pack、Flow/Veo 影片素材、去背、循環動畫與 QA。
**權責：** Chat 管理規格、進度和驗收；Codex 負責 Flow 提示詞、素材處理及實作。

## 1. 畫風、比例與產出規範

- **頭身比例：** 嚴格鎖定 **2.06 H 二頭身 Q 版**，參考 `ccc.jpg` 與最終核定正面母版。勿把貓耳／呆毛誤算入頭高。
- **畫風：** 乾淨俐落的 2D 日系賽璐璐平塗（Cel-shading），高解析度無 AI 雜訊、線條平滑清晰。
- **背景：** 以純平、無漸層、無陰影的 **`#00FF00` 綠幕**作為規格目標，供 `dsh_pet` 去背與循環動畫使用。

## 2. 核心色票鎖定（防暖紫漂移）

- **頭髮、貓耳、貓尾基色：** 冷調長春花藍／清透藍紫（Cool Periwinkle Blue-Violet），僅於中下段髮尾平滑漸層至柔和粉紫。
- **服裝底色：** 深靛藍／午夜藍紫（Deep Indigo / Midnight Navy-Violet），涵蓋外套主體、內搭背心、百褶裙、深色蝴蝶結和鞋面；嚴禁偏成暖調葡萄紫。
- **膚色：** 自然暖白桃色（Warm Peachy-Fair），不可因冷調整體色票而染藍。

## 3. 頭部、髮型與飾品

- **髮型：** 頭頂一根彎曲呆毛（Ahoge）、雙側小丸子包髮、蓬鬆大波浪長捲髮。
- **長側髮（Sidelocks）：** 雙耳側各一縷厚實的長微捲側髮，沿臉頰垂落至鎖骨下方，微覆外套帽緣前側；與帽繩分開、不糾纏。
- **獸耳與獸尾：** 毛茸茸大貓耳（內側粉紅配白色絨毛）。**僅一條**蓬鬆長貓尾、尾端白毛；尾根繫深靛藍金邊蝴蝶結，中央配金色五角星，不得複製尾巴或尾飾。
- **異色瞳：** 畫面左（角色右眼）洋紅／紫紅；畫面右（角色左眼）琥珀金黃。
- **畫面左側丸子頭：** 深靛藍金邊蝴蝶結，中央彩光漸層立體四角星髮飾，垂墜金色星星吊飾。
- **畫面右側丸子頭：** 亮粉紫金邊蝴蝶結，上方微立體倒角折面**十字星髮飾**（粉紫漸層、平緩中央脊、微展星芒狀端點、厚實圓潤金色外包邊），垂墜金色星星吊飾。
- **頸飾：** 雙子星發光頸環，畫面左為青藍光四角星、畫面右為粉紅光四角星。

## 4. 服裝結構（V4 核心定案）

- **內搭上衣：** 極簡深靛藍短版吊帶背心（Cropped Camisole Top），俐落平口／微弧領口；**取消愛心領與亮紫寬邊**。胸口正中央為**對稱金色四芒星**（邊緣微內凹），露出腰腹及粉色星座紋身。
- **外套版型：** 輕薄柔軟服貼布料，**禁止羽絨衣式膨脹**；雙臂自然貼近身體兩側。開襟連帽、**白色兜帽內裡**，固定單側滑落**角色左肩／畫面右側／星雲側**。
- **帽緣與拉鍊：** 沿帽緣內縮的平行金色滾邊，向下無縫銜接粗齒金色拉鍊。
- **門襟與帽繩：** 拉鍊兩側有垂直粉紫漸層門襟飾片（Placket Panels），金色帽繩附金色星星吊墜。
- **口袋及收邊：** 下擺兩側配置金色斜口袋（Welt Pockets），羅紋袖口及下擺收邊。
- **雙袖與衣身不對稱：**
  - 角色右／畫面左：深靛藍底色，袖身金色星座連線刺繡。
  - 角色左／畫面右：袖身及門襟外側左半邊衣身，無縫延續發光粉紫星雲銀河漸層（Nebula Galaxy Gradient）。
- **下裝：** 深靛藍百褶短裙，白色荷葉裙撐內襯，腰間金色星鏈及垂墜星星吊飾。

## 5. 腿部與鞋履（方案 A 定案）

- **角色右腿／畫面左：** 上方黑色橫向皮帶帶**單一金色方扣**；下方**無縫銜接**黑色交叉 X 型綁帶（兩端上緣直接連接橫向皮帶底部，無皮膚斷層，X 帶上無額外扣環）。下緣固定於星空漸層深紫長襪口，腳踝處疊穿一截白色微皺短襪口。
- **角色左腿／畫面右：** 自然垂墜的白色羅紋口泡泡襪（Ribbed-Cuff Slouchy Sock），不是節狀輪胎襪。
- **鞋履方案 A：** 深靛藍紫厚底潮鞋（Chunky Platform Sneakers），鞋面正中央有立體**金色五角星**飾扣及金色滾邊，厚底為粉紫至青藍漸層的雷射幻彩材質。

## 7. Pet Pack V4 基線切換政策

1. **V4.0.4 Final 文字規格 + 核定正面母版**同時作為正式視覺基準；V3 及 pre-V4 素材只保留歷史或技術測試地位。
2. 舊 `wave.webm`、`idle_breathe` 等產物不得直接升格成 V4 成品；**保留檔案與 QA 歷史，不刪、不覆寫**。
3. 可沿用 M0/M1/M2 已建立的後製技術、追溯機制、定位方法、VP9 Alpha、無音軌 `-an` 與黑／白／棋盤底視覺檢查，但須對新母版重新量測位置、色邊與循環。
4. **優先製作 V4 idle，再製作 V4 wave**；動作提示詞／Flow 生成策略交給 Codex 負責，Chat 不另行發佈競爭版本。
5. 每項動畫 Manifest 應記錄母版版本及 SHA、來源、提示詞／模型、FPS、區間、循環性、目標池及 QA／核定狀態。
6. 本文件新增於獨立 GitHub 文件分支；**不代表 Codex 的本地工作樹已同步**，更不代表母版檔案或動畫已被提交至遠端。
