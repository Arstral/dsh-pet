**狀態：使用者於 2026-11-26 核准納入角色規格的表演方向；以下六個動作為 BACKLOG，尚未核准製作或升格成品。**
**定位：** V4.0.4 Final 的「表演／動畫」補充規格，**不修訂**外觀、頭身比、配色、服裝、左右不對稱、核定圖片與 SHA-256。
**授權分工：** Chat 負責角色表演規格、版本規劃及驗收；Codex 負責具體 Flow/Veo 提示詞、程式與動畫後製；使用者最終核定。

## 1. 性格表演方向（behavioral art direction）

- **好奇、願意接近與觀察：** 偶爾微前傾、輕歪頭、耳朵小幅反應，像在注意到新鮮事。
- **機靈與發現感：** 有靈感時眼神變亮、姿態迅速聚焦、用短促而清楚的展示手勢讓觀眾理解「我發現了」。
- **俏皮而略帶小得意：** 手指輕點臉頰、含蓄的得意微笑、簡潔明確的單手指示；避免永遠誇張得意或過度賣萌。
- **親和、願意協作：** 輕快點頭、分享發現與鼓勵他人的動作，保持友好而非喧鬧或一直搶鏡。
- **帶一點小主持人／展示者氣質：** 看向觀眾、短暫展示／指引後，自然收回動作。
- **對比原則：** Idle 溫和安靜，受到點擊／靠近時才顯得比較有精神。小而精準的表情、手勢和貓耳反應，優先於不停跳躍或全身大幅晃動。

## 2. Flow / 動畫提示詞使用守則

1. 外觀、正面構圖、色彩、2.06H 頭身比例及左右定位，以 `HAKINEI_CHARACTER_SPEC_v4.0.4_Final.md` 與使用者核定 V4 WebP、Flow Working Master v1.0 為**上位基準**；本文件不得覆蓋。
2. 擬人化表演必須可從動畫直接看懂；描述微表情、耳朵、尾巴、頭部和手部的**具體可見動作**，避免只寫抽象性格形容詞。
3. 保留唯一一條尾巴；雙丸子、異色瞳及各側不對稱服裝／飾品不變。禁止因動作而長出額外手指、肢體、尾巴或改造衣裝。
4. 未特別授權不得新增手機、螢幕、漂浮星星、道具、第二角色或背景特效。參考圖中的這些元素只用來理解「分享發現」的動作語意。
5. Idle 不因本檔案而重開驗收；特殊動作需要清楚標示起始姿勢與自然回到 Idle 的結尾姿勢。非循環動畫不得假裝成無縫循環。
6. 保持固定鏡頭、全身在畫面內、既有綠幕與 V4 流程；正式格式／後製仍依獨立動作 QA 階段確認。
7. Flow 提示詞的撰寫與變更由 **Codex 獨立負責**；每次正式交付包含 Markdown 說明版和只含完整英文提示詞的 `FLOW_PROMPT_READY_TO_PASTE.txt`，兩者逐字一致。
8. 計畫、提示詞、Flow 素材、技術試作、QA、正式驗收是不同關卡；此文件的角色方向核准**不構成**任何待辦動作的生成、安裝或正式核定。

- Wave 的候選表演方向：從正面中立 Idle 姿勢出發，面向使用者，以一側手臂做兩次左右輕柔揮手、配合小幅歪頭或微笑，最後回到與 Idle 接近的中立姿勢。固定雙腳、固定鏡頭；是否調整表情、左右手、時間與尾巴幅度，需在 Wave 分鏡批准時再定。
